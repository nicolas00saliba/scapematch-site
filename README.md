# scapematch-site

Site público do ScapeMatch em [scapematch.com.br](https://scapematch.com.br).

A fonte da landing fica em [`apps/landing`](https://github.com/nicolas00saliba/scapematch/tree/main/apps/landing) do repositório principal [`nicolas00saliba/scapematch`](https://github.com/nicolas00saliba/scapematch). Este repositório só publica no GitHub Pages: a cada push em `main`, disparo manual ou a cada hora, o workflow copia `apps/landing`, grava o `CNAME` e faz o deploy.

Não edite HTML/CSS aqui — altere no repositório principal.
